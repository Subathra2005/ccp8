# CCP8 frontend

Run `npm ci` then `npm run dev` from this directory. Open http://localhost:5173 with the backend running on port 5001. Set VITE_API_BASE_URL only if the backend address changes. Never store the Gemini key in frontend variables.

See [setup](../README.md), [page states](../docs/ccp8/pages.md) and [API contracts](../docs/ccp8/api.md). Run `npm run build` and `npm run lint` to verify frontend changes.
